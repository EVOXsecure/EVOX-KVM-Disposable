# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** using GitHub's
"Report a vulnerability" button (Security → Advisories) in this repository (https://github.com/EVOXsecure/EVOX-KVM-Disposable, owner EVOXsecure).
Do not open a public issue and do not send e-mail.

Include: affected version (`evoxd --version`), what you did, what you expected, what happened.
Please do not include real passwords, keys or personal data.

## Scope

EVOX isolation limits are listed in the Full Manual, chapter "Known limits"
(for example Wayland, group `libvirt`, X11 input injection). Reports on these known limits are welcome but are not new findings.

## Supported versions

Only the latest release.
